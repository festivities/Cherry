Garden buttons

Owner only. These buttons appear in each player's own Garden, in the event column on the right of the screen. The game shows at most {{.GardenButtons.Max}}; while a season with a Garden icon runs (calendars.json), its icon takes a free place after these.

What the game allows: the picture is one of the game's own event pictures or a custom picture uploaded below (any text you see is part of the picture), and the action is a menu screen or a web page in the phone's browser. The label is only for staff: the game never shows it. A new button appears the next time a player's Garden loads. A removed or changed button stays on a player's screen until they restart the app. The column on the left, below the player picture, holds only the game's built-in buttons (packages, Play Pass, season pass, video ads, gacha target, comic guide, anniversary, back to My Garden). No server setting changes their picture, text or action.

Custom pictures (Cherry-made)

Pictures uploaded here are Cherry-made and kept apart from the game's originals: Cherry stores them in its database, never in the asset bucket. The game draws a button picture only from its own animation files. So Cherry hands these to the players inside its own copy of the small game file mainhome_button.aniproj: the original stays unchanged, with one entry added per picture, and the PNG files go into Cherry's own folder on the phone. Players download them without a prompt at their next app start (a few KB); until then a button with a new picture stays hidden for them. When no custom picture is left, players download the original file back. This needs the client's patcher lists from this server (streaming on); egress.json and the bucket make no difference.
