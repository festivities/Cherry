Garden buttons

Owner only. These buttons appear in each player's own Garden, in the event column on the right of the screen. The game shows at most {{.GardenButtons.Max}}; while a season with a Garden icon runs (calendars.json), its icon takes a free place after these.

What the game allows: the picture is one of the game's own event pictures (any text you see is part of the picture), and the action is a menu screen or a web page in the phone's browser. The label is only for staff: the game never shows it. A new button appears the next time a player's Garden loads. A removed or changed button stays on a player's screen until they restart the app. The column on the left, below the player picture, holds only the game's built-in buttons (packages, Play Pass, season pass, video ads, gacha target, comic guide, anniversary, back to My Garden). No server setting changes their picture, text or action.
