Server limits

These take effect while Cherry runs; nothing restarts. Each row shows the value in the server's configuration, the value set in this panel if there is one, and the value in effect now. A new connection cap applies to the next connection; a new request or frame rate applies to the next request or frame, for every player at once. Frame limits reach only connections opened after the change: a connection that is already open keeps the frame limits it started with.

Open game connections now: {{.Settings.OpenConns}} from {{.Settings.OpenAddrs}} addresses (every game port together).

Staff members

Staff sign in at this panel with Discord (two-factor authentication required). Owner has full access (Settings, Operator Documents, Broadcast, All balances, mass mail, avatar move/restore). Moderator handles Dashboard, Players (incl. single-player grants and mail), Moderation, Insights, Item names and Audit log. Helper has access to Item names only and lands straight there on sign-in. Changing a role or removing someone ends their open sessions at once.
